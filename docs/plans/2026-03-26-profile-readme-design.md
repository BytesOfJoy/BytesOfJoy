# GitHub Profile README Design (Cyber Pixel v2)

**Date:** 2026-03-26  
**Owner:** BytesOfJoy

## Goals
- Personal brand first (not hiring/portfolio-first).
- Visual direction: neon dark cyber arcade with a few bright modules.
- Keep high recognition while simplifying modules.

## Confirmed Decisions
- Aesthetic: neon dark + limited bright blocks.
- Primary objective: personal branding.
- Language: Chinese-English mixed copy.
- Module scope: keep `GitHub Stats + Snake`, remove `Top Langs` and activity graph.
- Contact links: none (display-only profile identity).

## Structure
1. Hero header with strong cyber-arcade identity.
2. Player card with pixel avatar and one-line mixed-language positioning.
3. Bright info strip (status and current quest) to create contrast.
4. Equipment badges (core stack) in dark cards with neon accents.
5. One stats panel only.
6. Snake contribution animation (dark palette).
7. Code-style about block as brand signature.

## Content Tone
- Short, punchy lines.
- Terminology mixes game/system metaphors with engineering vocabulary.
- Keep readability high, avoid overloading with too many widgets.

## Non-Goals
- No resume-style long text.
- No external contact section.
- No heavy module stacking beyond chosen core widgets.
